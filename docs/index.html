Neden rsipclient?

Ağır framework'ler ve JVM bağımlılıkları olmadan saf Rust ile yazılmış hızlı, güvenilir ve esnek Telekomünikasyon çözümü.

Çoklu Hesap Desteği

Aynı anda birden fazla SIP hesabını yönetin, bağımsız kayıt (REGISTER) ve çağrı akışlarını kontrol edin.

Görsel IVR Builder

Karşılama sesleri, zaman aşımı kuralları ve DTMF tuş menü eylemlerini görsel olarak kolayca yapılandırın.

Web Softphone & Audio

WebSocket ve Web Audio API ile doğrudan tarayıcınızdan arama yapın, konuşun ve mikrofon sesinizi kaydedin.

Rhai & Lua Eklentileri

Dahili Rhai ve Lua betik desteği sayesinde gelen ve giden çağrı senaryolarını anında özelleştirin.

Syslog (RFC 5424) & Tracer

SIP paket izleyici ve RFC 5424 Syslog desteği ile canlı logları merkezi log sunucularına aktarın.

Tek Binary & Pi Desteği

Sadece ~2-3 MB büyüklüğünde tek bir executable binary. Raspberry Pi ve Headless Linux sistemlerde sıfır bağımlılıkla çalışır.

Gelişmiş Web Dashboard

Web arayüzünden SIP hesaplarınızı, çağrı kayıtlarınızı, canlı sistem istatistiklerini ve Syslog ayarlarını yönetin.

Hızlı Kurulum & Kullanım

Saniyeler içinde rsipclient uygulamasını indirin ve tek komutla çalıştırın.

# Otomatik indirme ve yükleme scripti
irm https://raw.githubusercontent.com/mahirgul/rsipclient/master/install.ps1 | iex

# rsipclient servisini başlatın (Web UI varsayılan 8080 portunda açılır)
rsipclient --web-port 8080 --config config.toml
# Linux / macOS otomatik kurulum scripti
curl -proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/mahirgul/rsipclient/master/install.sh | sh

# Servisi arka planda veya terminalde başlatın
rsipclient --web-port 8080 --config config.toml
# Depoyu klonlayın
git clone https://github.com/mahirgul/rsipclient.git
cd rsipclient

# Release modunda derleyin
cargo build --release

# Başlatın
./target/release/rsipclient --web-port 8080
